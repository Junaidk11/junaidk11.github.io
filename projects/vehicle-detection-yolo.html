Computer Vision • Machine Learning • Deep Learning

Comprehensive research project implementing YOLOv5 (You Only Look Once) for multi-class vehicle detection and classification. The system identifies and classifies 15 different vehicle categories including brands (BMW, Ford, Toyota, etc.) and types (Coupe, Sedan, SUV, Truck) using deep learning techniques and custom-trained models with Google Colab integration and extensive performance analysis.

Overview

This comprehensive research project demonstrates the implementation of YOLOv5 (You Only Look Once) for multi-class vehicle detection and classification. The project focuses on creating a robust system capable of identifying and classifying 15 distinct vehicle categories including vehicle brands (BMW, Ford, Toyota, Chevrolet, Honda, Mercedes, etc.) and vehicle types (Coupe, Sedan, SUV, Truck).

The project showcases end-to-end machine learning pipeline development, from comprehensive dataset preparation and model training to extensive performance evaluation across multiple YOLOv5 variants. Using state-of-the-art deep learning techniques with rigorous analysis of confidence thresholds, image sizes, and loss functions, the research provides valuable insights into object detection optimization.

Key Achievement: Successfully trained custom YOLOv5 models achieving 0.8 mAP (mean Average Precision) across all variants, with comprehensive comparative analysis demonstrating superior performance of YOLOv5 Large for loss function optimization.

Core CNN Operations (Sequential Pipeline):
1. Convolution Operation
  • Purpose: Feature extraction from 2D/3D images
  • Mechanism: Filters slide across image to produce feature maps
  • Parameters:
    • Depth: Number of filters used
    • Stride: Pixel movement step size
    • Zero-Padding: Border handling for corner feature extraction
2. ReLU Activation
  • Function: Replaces negative pixels with zero
  • Purpose: Introduces non-linearity for real-world data modeling
  • Advantage: Better generalization vs other activation functions
  • Optimization: Enables easier gradient descent training
  • Problem Solved: Without activation, networks produce only linear outputs (limited complexity)
3. Pooling Operation
  • Method: Calculates Average or Max in sliding windows
  • Dimensionality Reduction: Reduces input image size
  • Overfitting Control: Removes less important parameters
  • Generalization: Prevents model restriction to training dataset

🎯 YOLO Algorithm Architecture

Core Concept: "You Only Look Once"

Revolutionary Approach: Unlike traditional methods that examine images multiple times, YOLO processes the entire image in a single pass, making it extremely fast for real-time applications.

Architecture Overview:
  • Network Type: Fully-Convolutional Neural Network
  • Structure: 24 convolutional layers + 2 fully-connected layers
  • Detection: 24 conv layers handle object detection
  • Classification: 2 FC layers manage class prediction
Grid-Based Detection System

Process:

  1. Input image (N×N) divided into M×M grid cells
  2. Each grid assigned fixed number of bounding boxes
  3. Grid responsible for objects whose center falls within it
  4. Output: Tensor with object information for each grid cell

Prediction Vector per Grid:
Y = [pc, bx, by, bw, bh, c1, c2, c3, ...]

  • pc: Confidence score
  • bx, by: Box center coordinates (relative to grid)
  • bw, bh: Box width/height (relative to image)
  • c1, c2, c3: Class probabilities

📊 Key Performance Metrics

Intersection over Union (IoU)

Formula: IoU = Area of Overlap / Area of Union

  • Range: [0, 1] - closer to 1 = better prediction
  • Threshold: IoU > 0.5 considered good prediction
  • Usage: Measures bounding box accuracy

Good IoU > 0.5

Poor IoU < 0.5

■ Ground Truth    ■ Prediction
Non-Max Suppression

Prevents multiple detections of same object:

  • Selects prediction with highest IoU
  • Removes nearby boxes below IoU threshold
  • Repeats until all boxes processed
  • YOLO threshold: 0.25 IoU
Mean Average Precision (mAP)
  • Precision: Accuracy of positive predictions
  • Recall: Ability to find all positive instances
  • AP: Weighted mean of precisions at recall thresholds
  • mAP: Average of AP across all classes

🚀 YOLOv5 Architecture & Innovations

YOLOv5 Evolution (2020)
  • Framework: First YOLO built entirely in PyTorch (vs Darknet)
  • Developer: Glenn Jocher
  • Based on: YOLOv3 with significant improvements
  • Status: Continuous development with daily updates
  • Architecture: 191 layers total across 3 components
Three-Stage Architecture:
  1. Backbone: Cross-Partial Networks for feature extraction
  2. Neck: Path Aggregation Networks for feature fusion
  3. Head: 3 anchor boxes per grid cell for prediction
Advanced Features
Multi-Scale Detection:

For 416×416 input, YOLOv5 makes predictions on:

  • 13×13 grid: Large object detection
  • 26×26 grid: Medium object detection
  • 52×52 grid: Small object detection
Activation Functions:
  • Hidden Layers: Leaky ReLU (solves "dying ReLU" problem)
  • Output Layer: Sigmoid (vs Softmax in earlier versions)
  • Advantage: Non-mutually exclusive classes (e.g., "Woman" + "Person")
Data Augmentation:
  • Scaling: Image size variations
  • Color Space: HSV adjustments
  • Mosaic: Novel 4-image combination technique

Compound Loss Function

Optimization Algorithm: Stochastic Gradient Descent

Three Loss Components:

  1. Classification Loss:
    Difference between ground truth and predicted class probabilities
  2. Localization Loss:
    Error between predicted and ground truth bounding boxes
  3. Confidence Loss:
    Difference in box confidence scores

Final Loss = Sum of all three error components
